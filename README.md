**Накопление материала на поверхности**

Автор: Малгаждар Жалгас

Unity-проект демонстрирует процедурное изменение Mesh для симуляции накопления материала на поверхности.

Управление:
  WASD — перемещение зоны воздействия.
  Space — накопление материала.
  F — сброс поверхности.

Реализация:
  Высоты вершин хранятся в двумерном массиве heightMap. При накоплении материала обновляются значения высот, после чего обновляется Mesh.

Фактически затраченное время: X часов.

Ограничения:
  Качество геометрии зависит от плотности сетки.
  Обновление нормалей и Mesh может снижать производительность при увеличении разрешения.

Возможные улучшения
  Оптимизировать обновление только изменённых вершин.
  Добавить более точное сглаживание высот.
  Улучшить производительность при высокой плотности сетки.

Были сняты видео демонстраций каждого этапа в ./VIDEOS
